Google Places API

A extensão usa a Google Places API (New) como fonte de dados comercial autorizada. Crie uma chave de API no Google Cloud Console, habilite a "Places API (New)" e ative o faturamento do projeto (a API é paga, mas possui cota gratuita mensal).
