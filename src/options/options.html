Configurações do WhatsProspect

Fonte de dados

Por padrão, a busca é feita automatizando a navegação no próprio Google Maps (grátis, mas fora dos Termos de Serviço do Google — veja o aviso no popup). Nenhuma chave é necessária para esse modo.

Opcionalmente, o código já inclui um cliente para a Google Places API (New) (src/lib/placesApi.js), uma fonte oficial e paga, caso você queira migrar para ela no futuro para reduzir o risco de bloqueio. Se quiser usá-la, crie uma chave no Google Cloud Console e cole abaixo — mas isso ainda não está conectado à busca do popup nesta versão.

Sincronização com Supabase (login Google)

Opcional. Conecte um projeto Supabase para guardar os leads encontrados num banco na nuvem (além do histórico local), com login via Google. Sem isso configurado, a extensão continua funcionando normalmente, só que os leads ficam salvos apenas neste navegador.

↑ Essa é a URL de redirecionamento fixa desta extensão. Ela precisa estar na lista de "Redirect URLs" do seu projeto Supabase — a Opção A abaixo faz isso sozinha; na Opção B você cola manualmente.

Opção A — Provisionar automaticamente

Cole um Personal Access Token do Supabase (crie um em supabase.com/dashboard/account/tokens, de preferência com escopo limitado). A extensão cria o projeto, roda o schema.sql e registra a URL de redirecionamento sozinha. O Client ID/Secret do Google (campos opcionais abaixo) você ainda precisa criar manualmente no Google Cloud Console — isso não tem como ser automatizado (é uma trava de segurança do próprio Google) — mas se preenchidos aqui, a extensão os configura no Supabase pra você.

Opção B — Configurar manualmente

  1. Crie um projeto em app.supabase.com (grátis).
  2. No SQL Editor do projeto, rode o conteúdo de supabase/schema.sql (deste repositório) para criar a tabela de leads com Row Level Security.
  3. Em Authentication → Providers → Google, habilite o provedor e informe um Client ID/Secret OAuth (mesmo do Google Cloud Console mencionado acima).
  4. Em Authentication → URL Configuration → Redirect URLs, adicione a URL mostrada acima.
